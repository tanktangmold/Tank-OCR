# 小小中文 / ちいさな中国語

给住在日本、日常说日语的孩子用的**初级中文**小工具。独立项目，不依赖 Tank-OCR。

孩子说出自己喜欢的东西（足球、C罗、绘本……），就会得到：

- 一句一图的连续故事
- 很短的中文句型，例如「谁 + 几岁 + 开始 + 做什么」
- 点字读字、点句读句（中文朗读）
- 漫画 / 绘本 / 写实三种画风
- 相关童书线索（课文是原创短句，不照抄原书）

足球会走到 **C罗小时候** 的故事：从小岛踢球，到成为足球运动员。

## 运行

需要 [Go 1.22+](https://go.dev/dl/)。

```bash
cd xiaoxue-zhongwen
go test ./...
go run .
```

浏览器打开 <http://127.0.0.1:8080/> 。

端口可用环境变量改：

```bash
LISTEN_ADDR=127.0.0.1:3000 go run .
```

朗读用浏览器自带的中文语音。Chrome 里如果没有中文声，到系统语音设置里打开「中文」。
