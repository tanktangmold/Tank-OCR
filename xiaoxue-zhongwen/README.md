# 小小中文 / ちいさな中国語

给住在日本、日常说日语的孩子用的**初级中文**小工具。独立项目，不依赖 Tank-OCR。

## 一个月 · 每天15分钟

主线是 **C罗成长故事**，30天连成一篇长故事：

1. 第1周：小岛、家里的爱、三岁第一脚  
2. 第2周：离开家、里斯本、想家也不放弃  
3. 第3周：心跳手术、被人叫爱哭、把话变成力量  
4. 第4周：去英国、进球、有名也不忘记家  

每天大约15分钟：一句一图、点字发音、点句发音，听完当天的故事再做4道小练习。**完成当天课程后，解锁1个游戏**（听音选词 / 对不对 / 组句进球）。

## 多个孩子 · iPad

- 每个孩子一个头像，进度分开存，互不影响  
- 同一台 iPad 可以换人；同一 Wi-Fi 下多台 iPad 可同时打开  
- 按钮大、可点、适合手指；可加到主屏幕当网页 App  

## 运行

需要 [Go 1.22+](https://go.dev/dl/)。

```bash
cd xiaoxue-zhongwen
go test ./...
go run .
```

电脑浏览器打开 <http://127.0.0.1:8080/> 。  
iPad 请连同一 Wi-Fi，用页面上显示的局域网地址打开。

```bash
LISTEN_ADDR=0.0.0.0:8080 go run .
```

朗读用浏览器自带的中文语音（Safari / Chrome 都可以）。如果没有中文声，到 iPad 的「辅助功能 → 朗读内容 / 口语内容」里打开中文。

## 目录

```
xiaoxue-zhongwen/
  main.go           独立 HTTP 服务（默认同网可访问）
  learn/            30日课程、句型短句、多孩子进度、游戏
  handler/          API
  static/           iPad 阅读页和插图
  data/             运行后自动生成，保存每个孩子的进度
```

课文是原创短句，根据公开的成长经历改写成儿童能读的中文，不照抄任何传记原文。
